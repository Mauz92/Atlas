# apps/web — React + TypeScript client (PWA)

Intended: the browser/PWA client. React + TypeScript, a maintained accessible component
library, generated API types from the backend OpenAPI schema, CodeMirror 6 for Markdown
editing, and Web Push (VAPID) for desktop notifications.

Not yet implemented. First work is Milestone 1 (app shell, auth-gated routes).
See `docs/ARCHITECTURE.md` §8 and `docs/ROADMAP.md` (M1-06, M2-04).
